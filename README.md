# IP Sweeper Port Scanner (ISPS)

Sweeps all the IP's/Hosts in your network and scans the open ports in all of them. 
- Made by TechRebel
  
# USAGE

1. git clone https://github.com/TechRebel123/IP-Sweeper-Port-Scanner-ISPS.git

- If you want to scan common TCP ports OR ALL TCP ports, use:

--> python3 portscanner.py (ip)/(url)
